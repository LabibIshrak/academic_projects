# Mystic Mage

A simple game/graphics project built using C++ and OpenGL.

## Setup & Compilation
To compile this project, you will need an OpenGL environment set up (like FreeGLUT/MinGW on Windows or standard OpenGL libraries on Linux).

Example compilation command using g++ (assuming GLUT is installed):
```bash
g++ mystic_mage.cpp -o mystic_mage -lglut -lGLU -lGL
```
